# Dedicated Server Port Rule

Whenever starting development servers:
* **Toarps Herrklubb** MUST ALWAYS run on port `1981` (e.g. `python manage.py runserver 1981`).
* **Prediction Engine** MUST ALWAYS run on port `2028` (e.g. `python manage.py runserver 2028`).

Do NOT run either application on default 8000 or 8001 ports.
